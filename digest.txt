🧠 模型

① Claude Sonnet + Opus 顾问工具提升性能
Anthropic 推出 Advisor Tool（Beta），允许 Sonnet/Haiku agent 在遇到复杂决策时"打电话给 Opus"获取建议，整个过程在单次 API 请求内完成。评测显示，Sonnet+Opus 顾问组合在 SWE-bench Multilingual 上比单独 Sonnet 高 2.7 个百分点，同时每次任务成本降低 11.9%。petergyang 也观察到目前没有任何模型在 OpenClaw 场景下接近 Opus 的水平。
🔗 https://x.com/claudeai/status/2042308629940855048 · https://x.com/alexalbert__/status/2042329150086922574 · https://x.com/petergyang/status/2042472016566239320

② Google Gemini Lyria 3 音乐模型向用户全面开放
Google Gemini App 上线 50 天内已生成超过 1 亿首歌曲，为庆祝这一里程碑，音乐模型 Lyria 3 现免费向所有用户开放，每天可生成最多 5 首完整曲目（每首约 3 分钟）。官方表示后续还将推出更多创意模型回复功能。
🔗 https://x.com/joshwoodward/status/2042318148851188151

🤖 Agent/编程

③ Claude Code 功能更新：Bedrock/Vertex 集成 & Monitor Tool
Anthropic 已大幅简化 Claude Code 与 AWS Bedrock 及 Google Vertex 的配置流程，降低企业接入门槛。此外，Claude Code 新增 Monitor Tool，可监听开发服务器的实时错误输出，需在 prompt 中显式调用（如"start my dev server and use the MonitorTool to observe for errors"）。
🔗 https://x.com/_catwu/status/2042345489778331915 · https://x.com/trq212/status/2042335178388103559

④ Agentic 基础设施成为云计算新方向
Vercel CEO rauchg 指出，Agentic Infrastructure 是云计算的未来：一方面为 Claude Code、Codex、Cursor 等编程 agent 提供专属基础设施；另一方面支持长时运行、沙箱隔离和 token 分发网络，以部署生产级 agent。shadcn init 每秒被执行一次，印证了新软件创建规模的急剧扩大。
🔗 https://x.com/rauchg/status/2042358253510963384

⑤ GBrain：为 OpenClaw/Hermes Agent 提供万级文件记忆
YC 合伙人 garrytan 开源了 GBrain 工具（MIT 协议），专为 OpenClaw 和 Hermes Agent 设计，可让 agent 对 10,000+ 个 Markdown 文件实现完整的长期记忆召回。项目部署在 Railway 上，安装脚本通用于两种 agent。
🔗 https://x.com/garrytan/status/2042497872114090069

📈 商业/观点

⑦ AI 能力认知鸿沟正在扩大
Karpathy 指出，许多人因长期停留在 ChatGPT 免费层而对 AI 能力认知严重滞后，而真正使用最新 agentic 模型的用户则对 AI 理解截然不同；"OpenClaw 时刻"之所以影响巨大，正是因为它首次让大批非技术用户直接体验了最新 agent。Levie 进一步指出，AI 采用呈现"两座城市"格局——大多数用户停留在聊天工具层，少数人已在部署长时运行 agent 执行真实生产任务，后者的生产力差距将越来越大。
🔗 https://x.com/karpathy/status/2042341482531864741 · https://x.com/levie/status/2042469771275329594

⑧ Prompting 是高价值长期技能
trq212 和 levie 均认为"提示工程"不会消亡，而是类似写作或公开演讲的高杠杆沟通技能——本质是向 agent 清晰传达完成任务所需的一切信息。trq212 将其定位为扩大人类与 agent 之间"带宽"的核心能力。
🔗 https://x.com/trq212/status/2042335178388103559 · https://x.com/levie/status/2042469771275329594

⑨ 软件自动化的真实需求被严重低估
Levie 认为业界普遍低估了"非传统软件"领域的自动化需求——不是手机上多一个 app，而是为企业全天候自动化各类流程的后台软件。大多数公司此前根本没有能力构建这类软件，AI agent 正在打开这扇门。
🔗 https://x.com/levie/status/2042469771275329594


🎙 Podcast

Ep 84: OpenAI’s Chief Scientist on Continual Learning Hype, RL Beyond Code, &amp; Future Alignment Directions

OpenAI首席科学家Ako Paioki透露，公司正按计划推进目标：在今年9月前实现"研究实习生级别"的AI系统，并在2028年3月前完成全自动化AI研究员的构建，目前OpenAI内部已将Codex工具用于处理大部分编程工作。Paioki将这两个里程碑区分为：系统能够在多大程度上自主运行以及任务的具体程度，但强调"解决对齐问题"这类开放性指令在短期内仍无法实现。数学和物理基准测试因其可验证性和难度的可扩展性，成为模型能力提升的关键参照系，近期在这些领域的突破预示着通用智能的实质性进步。在对齐研究方面，Paioki强调长期核心挑战在于价值观的泛化——即理解模型在陌生情境下会回归哪些默认价值观——并将持续学习定位为当前研究的核心方向，而非被忽视的问题。
