🧠 模型

① Anthropic 发布 Claude Opus 4.8
Claude Opus 4.8 带来三项核心升级：动态工作流支持多 Agent 协作、快速模式性能提升 2.5 倍、代码质量提升 75%。同时推出「工作强度」调节（高/中/低），让用户自主控制推理深度。定价保持不变，继续与 Opus 4.7 持平。
🔗 https://www.anthropic.com/news/claude-opus-4-8

② Google DeepMind 推出 Gemini 3.5
新版本为下一代边界模型，专为复杂多步 Agent 工作流优化。同步推出 Gemini Omni，扩展多模态能力。DeepMind CEO Demis Hassabis 在 Google I/O 表示 AGI 时间线为 2030 年左右。
🔗 https://deepmind.google/blog

③ Mistral 发布 Vibe Agent 重塑工作流
将 Le Chat 升级为统一 Vibe AI Agent，集成 Google Workspace、Outlook、SharePoint、Slack、GitHub。新增 VS Code 插件和 CLI 模式，支持远程编码和 PR 管理。企业客户已包括空客、宝马、ASML。
🔗 https://mistral.ai/news/vibe-agent

🔒 安全

④ OpenAI 发布 Frontier Governance 框架
OpenAI 提出《前沿治理框架》，从系统风险评估、第三方评估基金、利益相关方参与三方面建议，为 AGI 级别能力的模型监管制定标准。同步推出选举保护措施 2026，应对恶意使用风险。
🔗 https://openai.com/news
