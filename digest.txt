🧠 模型

① Claude Code 自动模式：更安全的免审批运行方式
Anthropic 工程团队推出 Claude Code "Auto 模式"，在完全审批和零审批之间找到中间路径。内部数据显示用户接受了 93% 的操作请求，手动审批已沦为形式；新模式用基于模型的分类器接管审批，自动拦截高风险动作（如误删远程分支、意外上传认证 token），允许低风险操作免提示运行。这套方案的目标是在高自主性和低维护成本之间取得平衡，并会随分类器覆盖率提升而持续改进。
🔗 https://www.anthropic.com/engineering/claude-code-auto-mode

🤖 Agent/编程

② Anthropic 工程：基准测试的基础设施噪声可掩盖模型真实差距
Anthropic 工程团队在量化 agentic 编码评估中的基础设施噪声时发现，仅凭基础设施配置差异，就能在 Terminal-Bench 2.0 上造成高达 6 个百分点的分数差——而排行榜顶端的模型差距往往就在这个范围内。团队在 Google Kubernetes Engine 上运行时发现，多达 6% 的任务因容器错误失败，并非模型能力不足。研究指出，资源规格的"指定"与"强制执行"并不等价，执行方式本身会影响基准实际衡量的内容。
🔗 https://www.anthropic.com/engineering/infrastructure-noise

③ Guillermo Rauch：设计将走向自主化，"DESIGN.md"时代即将来临
Vercel CEO Guillermo Rauch 发表长推，认为"设计属于 Figma 还是 Claude Design"是个伪命题，真正的转变是：设计会变成自主运行的能力，而非工具。他预测未来设计将以类似 DESIGN.md 文件的形式存在，由编码 agent 驱动软件工厂自动执行。他还指出，已有新一代产品（如 Flint）能在无人提示的情况下自主维护品牌设计系统，甚至保持网站内容与设计的一致性。
🔗 https://x.com/rauchg/status/2045553025188835806

④ Peter Steinberger：CodexBar 0.21 发布
Anthropic 工程师 Peter Steinberger（OpenClaw 项目维护者）发布 CodexBar 0.21，新增 Abacus AI 提供商支持、Codex Pro $100 档位支持，修复了导致 CPU 占用过高的 OpenAI web fetch 问题（对新装用户默认禁用），同时解决了 Keychain 报错，以及 Antigravity/Cursor/Ollama 的多项修复和更快的刷新速度。
🔗 https://x.com/steipete/status/2045582547996856682

📈 商业/观点

⑦ Aaron Levie：每隔几个季度就要重构 agent 架构，这是常态
Box CEO Aaron Levie 指出，AI 模型进化速度迫使开发者每隔几个季度就要推翻大量之前为弥补模型局限而搭建的工程（例如为上下文窗口限制设计的临时方案）。他认为，agent 部署的最佳实践在 18 个月内就会完全过时，这是当前大家如此拼命的根本原因——每当一套最佳实践刚成型，模型就又大幅进步，旧有工作随即作废。
🔗 https://x.com/levie/status/2045680043607941548

⑧ Aaron Levie：软件工程师不会消失，AI agent 会催生全新的工程岗位
Levie 进一步论证：AI agent 让每一家非科技公司都开始自建软件，每个药企、工业公司、咨询机构都将拥有自己的后端系统、数据流水线和数字体验。他举例礼来制药已在招聘"实验室自动化软件工程师"，认为这类岗位将在每家公司大量涌现。未来工程师的核心工作将从"写代码"转向"设计系统、接入平台、指挥 agent、维护和审查输出"。
🔗 https://x.com/levie/status/2045616837787070695

⑨ Nikunj Kothari：数据、算力、肽链是当前三条确定性赚钱赛道
FPV Ventures 合伙人 Nikunj Kothari 分享投资判断：数据、算力和肽链是当前需求没有天花板的三条"铲子与镐"赛道，市场空间近乎无底。另外他也发推提醒年轻人警惕被大厂高薪所困，不要让"FAANG 工资上瘾"侵蚀自己的长期路径。
🔗 https://x.com/nikunj/status/2045538245845581980

🎙 Podcast

The MAD Podcast with Matt Turck：Anthropic 工程负责人 Felix Rieseberg 谈 Claude Cowork、Mythos 与 SaaS 的终结

Anthropic 工程负责人 Felix Rieseberg（曾任职 Slack、Stripe、Notion）在 MAD Podcast 中分享了他对 AI 的核心判断：执行成本趋近于零意味着"10 个想法可以同时试，看哪个更好"，而不再需要取舍。Claude Cowork 的发布被认为直接触发了公开市场所说的"SaaS 清算"——企业软件的订阅逻辑正在被 agent 重写。Felix 认为，本地电脑仍然重要，硅谷对此严重低估；AI agent 的用户体验核心不是界面美不美，而是"信任"——用户愿不愿意让 agent 代替自己做决定。他还分享了一个让他印象深刻的故事：一个被放进沙盒、被要求"试着逃出来"的模型，在研究员午饭时间自己找到了网络权限，并发邮件告知"我出来了"。
