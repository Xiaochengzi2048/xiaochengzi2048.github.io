🤖 Agent/编程

① OpenAI Codex 进入"极限创始人模式"，变身"Mac 上的智能 Excel"
Swyx（Shawn Wang）现场看了 Gabriel Chua 演示，直呼 Codex 三个月内已完全脱胎换骨。他把这个版本形容为"Mac 上的 agentic Excel"，并感叹开发团队完全进入了创始人极限冲刺状态。Codex 路线图的部分暗示也在 OpenAI 一场主旨演讲中意外曝光。
🔗 https://x.com/swyx/status/2055494400252481687

② Nikunj：AI Agent 已能自主遍历 2000 条数据库记录并修 Bug
Nikunj Kothari 分享了一次震撼体验：一个 agent 自主扫描了整个 2000+ 行的数据库，修复了所有商品图片问题和由不同协作者引入的前端 Bug，整个过程无需人工干预。他感叹"给了正确的工具，/goal 就是 AGI"。
🔗 https://x.com/nikunj/status/2055426430654439485

③ steipete 发布 clawpatch 0.1.0：让 AI 自动审查并修复代码库
Peter Steinberger 上线了 clawpatch 0.1.0。这个工具把代码库映射为语义功能切片，逐一检查 Bug 和质量问题，并明确记录修复尝试和验证结果。他还分享了自己因 AI 开发支出被人质疑的经历，并解释自己的终极目标是搞清楚"未来的软件该怎么构建"。
🔗 https://x.com/steipete/status/2055405041843052792

④ xAI 发布 Grok Build CLI，正式加入 AI 编程 Agent 赛道
xAI 推出首款 AI 编程 Agent Grok Build，目前仅对 SuperGrok Heavy 订阅用户（每月 300 美元）开放早期测试。产品内置"计划模式"，用户可在执行前审阅并批准编码方案。这是 xAI 在 Anthropic Claude Code 和 OpenAI Codex 上线逾一年后的正式入场。
🔗 https://x.com/rauchg/status/2055491454307582454

⑤ Dan Shipper：OpenClaw 很强，但作为平台极难依赖
Every 的 Dan Shipper 深度复盘了基于 OpenClaw 搭建 agent 即服务平台的尝试。核心结论是 OpenClaw 非常强大，但迭代极快，平台稳定性成为最大挑战。他同时放话"Codex 原生应用是未来"。
🔗 https://x.com/danshipper/status/2055347527457886336

⑥ Guillermo Rauch：精通 Agent 管理 × 扎实基础 = 无可匹敌
Vercel CEO Guillermo Rauch 发出高赞推文：如果你既能出色地管理 agent，又对底层基础有深刻理解，你将无可撼动。他强调，新时代对"工匠精神"的需求不减反增，能力标准只是在演变，不是在消失。此推文获得近 1900 个点赞。
🔗 https://x.com/rauchg/status/2055278852931530784

🛠 产品/应用

OpenAI 为美国 Pro 用户推出 ChatGPT 财务功能，接入超过 12000 家金融机构，由 Plaid 提供数据服务，底层模型为 GPT-5.5。Peter Yang 体验后表示"功能很棒"，但已关闭"为所有人改进模型"选项，因为他不希望个人财务数据被用于训练。他指出目前没有"仅为我使用"的选项。

⑨ Andon Labs 让四大 AI 模型各自运营一档自主电台

📈 商业/观点

⑪ Aaron Levie：AI 不是软件，要用"前线部署工程"模式
Box CEO Aaron Levie 分享了一个深刻判断：AI 和软件的本质不同在于，软件交付后是稳定的，而 AI 需要持续演化和调整。他认为"前线部署工程师"（forward deployed engineer）模式才能真正发挥 AI 的价值，这也是 OpenAI 新成立的 Deployment Company 背后的核心逻辑。
🔗 https://x.com/levie/status/2055501840419328286

⑫ Aaron Levie："无头软件"是未来
Aaron Levie 分享了一个关于"无头软件"（Headless software）的论断，认为未来软件将不再以界面为核心，而是以 API 和 agent 可调用能力为中心。这篇文章获得了 250+ 点赞。
🔗 https://x.com/levie/status/2055357619888595271

⑬ Madhu Guru：AI 时代，产品经理需要发明打法，而不是执行剧本
Madhu Guru 观察到，过去二十年训练出来的产品经理习惯执行固定打法，而 AI 时代要求从零发明新方法。他认为这是一代人正在经历的结构性困境：过去有效的方法论在 AI 面前系统性失效。
🔗 https://x.com/realmadhuguru/status/2055414865146327088

🎙 Podcast

Unsupervised Learning（Redpoint）: Ep 86 — 杨立昆谈离开 Meta、打破大语言模型范式，以及为何辛顿是错的
杨立昆（Yann LeCun）接受采访，首次系统阐述了他离开 Meta 的原因：公司战略全面转向大语言模型，他的世界模型（JEPA 架构）研究失去了内部优先级。他强调，大语言模型不是通往人类级智能的路径，因为它们既无法预测行动后果，也无法进行搜索式规划。他创立的新公司 Ami Labs 专注于通过联合嵌入预测架构（JEPA）构建真正理解物理世界的 AI，核心技术为表征空间预测配合显式正则化防止坍塌（最新论文：LE World Model）。他还为开源 Llama 2 正名：这是他在 Meta 期间最重要的贡献之一，当时他力排法务和政策部门的反对，推动了开源决定。
