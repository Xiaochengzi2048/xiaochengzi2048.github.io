🤖 Agent/编程

① Karpathy 在红杉 Ascent 2026 炉边对话阐释 LLM 新范式
三个新应用场景：1）menugen——整个应用完全由 LLM 处理，输入图像输出图像无需传统代码；2）用 .md 文件替代 .sh 安装脚本，LLM 直接读文字指令智能适配目标系统；3）知识库——只有 LLM 才能处理非结构化知识的计算。第二个主题是 LLM 能力的「参差性」：同一模型能重构 10 万行代码库，又会叫人开车去洗车场。原因在于训练数据分布和 RL 激励机制的覆盖范围，「在轨」的任务飞驰，「越野」则举步维艰。
🔗 https://x.com/karpathy/status/2049903821095354523

② Swyx：「编程 agent 冲破围栏」是今年最重要的主题
不只是程序员，所有知识工作者今年都会被 AI agent「上线」。他在 AIE EU 闭幕演讲里分享了用 agent 团队运营 AI Engineer 社区（每月服务 100 万开发者）的实践——用 Devin 和 Town.ai 处理从内容到出租龙虾充气玩具的各种任务。核心观点：大多数人还没有足够努力地把 agent 用进日常工作。
🔗 https://x.com/swyx/status/2050068468498842058

📈 商业/观点

⑧ Aaron Levie：agent 时代的软件计费模式将走向三轨并行
Box CEO 系统拆解未来软件商业模式：1）人的座位计费不会消失，但必须捆绑 API 用量额度；2）长期驻留的 agent 可能也有「座席」，但定价逻辑和人完全不同，无法按人头算；3）按量消费将成为主流，尤其是 agent 自主行动时。headless 使用的增长理论上无界，拒绝 headless 的软件平台将被淘汰。
🔗 https://x.com/levie/status/2050051426446152159

⑨ Garry Tan：GBrain 已与 Mempalace 分化成独立品类
YC 总裁认为 GBrain 现在明显针对 OpenClaw/Hermes 个人 AI 场景，而非通用的「海底捞针」检索。推荐在 Karpathy 风格知识库上加装 GBrain。GBrain 已 MIT 协议开源。
🔗 https://x.com/garrytan/status/2050095919157350644
