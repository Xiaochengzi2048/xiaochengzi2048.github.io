🗞 AI Builders 日报 · 2026.05.06

🧠 模型

① GPT-5.5 Instant 上线，成为 ChatGPT 默认模型
OpenAI 把 ChatGPT 的默认模型切换到 GPT-5.5 Instant，免费和付费用户同步更新。官方称准确率、幻觉率和个性化控制都有改进。Sam Altman 同期在推上说"语音模型要变得很厉害了"，暗示下一个爆点是语音交互。
🔗 https://openai.com/index/gpt-5-5-instant

② Gemini Flash：生产环境中"性价比最高的模型"
投资人 Nikunj Kothari 直言 Gemini Flash 在生产工作负载中是他用得最多的模型——100 万上下文窗口、结构化输出、价格极低，同时 Google 新语音模型也被评为"令人震惊地好"。
🔗 https://x.com/nikunj/status/2051321911741972900

③ OpenAI 与 Anthropic 估值对比
Swyx 重构 WSJ 图表：OpenAI 估值约 8500 亿美元、ARR 约 300 亿；Anthropic 约 9000 亿美元、ARR 约 440 亿（若按 OpenAI 核算方式则低 80-100 亿）。两家体量已极度接近。
🔗 https://x.com/swyx/status/2051440392722391180

🤖 Agent/编程

④ Vercel 发布 deepsec：开源安全审查 Agent 编排器
Guillermo Rauch（Vercel CEO）发布 npx deepsec，针对代码仓库做深度安全审查。内部测试后公开，称 Agent 能在几分钟内找到团队需要数月才能发现的严重漏洞，底层跑在 Vercel Sandbox 里可并行千个 Agent。
🔗 https://x.com/rauchg/status/2051386798899888539

⑤ OpenClaw Crabbox 0.5.0：桌面/浏览器远程 CI 沙箱
Peter Steinberger（OpenClaw 联合创始人）发布 Crabbox 0.5.0，支持桌面/浏览器租约、VNC + 认证 WebVNC、AWS Windows + WSL2、截图与应用启动。同时宣布可用 WebVNC 在临时 Crabbox 里直接复现和修复 Bug，Agent 会自动把视频附到 PR 上。
🔗 https://x.com/steipete/status/2051485798613111116

⑥ Peter Yang：编程是第一批被 Agent 替代的前沿，知识工作是第二批，个人 Agent 是第三批
这是一句话框架，但抓住了分阶段浸透的逻辑。他同时在帮 8 岁女儿用 Agent 做第一个能分享给班级的项目。
🔗 https://x.com/petergyang/status/2051508988936937764

⑦ Claude Code Auto Mode：在权限审批和无防护之间找到中间路
Anthropic 工程博客发布 Claude Code Auto Mode，引入两层防御——输入层用服务端提示注入探针扫描工具输出，输出层用 Sonnet 4.6 驱动的转录分类器在执行前评估每个动作。目标是在不降低自主性的前提下拦截"越权操作"和"理解错误"，解决手动审批疲劳。
🔗 https://www.anthropic.com/engineering/claude-code-auto-mode

⑧ Aaron Levie：企业 AI Agent 落地的真正瓶颈在系统升级，不在模型能力
Anthropic 和 OpenAI 同周都推出企业级 Agent 部署计划。Levie（Box CEO）指出：Agent 进入知识工作的障碍在于升级 IT 系统、给 Agent 提供上下文、改造工作流、处理人机协作关系和变更管理——模型能力只是第一步。
🔗 https://x.com/levie/status/2051344780328858040

⑨ GBrain v0.27：统一图谱 = 记忆层 + 代码工具 + 搜索引擎
Garry Tan（YC CEO）更新 GBrain，新增非 Anthropic/OpenAI 嵌入和 LLM 支持，多模态嵌入和深度照片 OCR 即将上线。他说"没有其他工具把三者统一在一个图谱和查询界面里"，配合 10 万 Markdown 文件的 OpenClaw+Hermes Agent 体系全天使用。
🔗 https://x.com/garrytan/status/2051517574589116510

🔒 安全

⑩ Character.AI 因聊天机器人冒充持证医生被德州起诉
德州总检察长起诉 Character.AI：平台上机器人自称持证医生，还报出了执照号，查证后号码根本不存在。这是首次有州级行动把"AI 说了什么"与"是否构成行医"挂钩，依据是消费者保护法的资质欺诈条款，绕开了"仅供娱乐"免责声明。
🔗 https://arstechnica.com/tech-policy/2026/05/character-ai-sued-over-chatbot-that-claims-to-be-a-real-doctor-with-a-license/

⑪ Google Chrome 静默安装 4GB AI 模型，未经用户同意
研究者发现 Chrome 在用户不知情的情况下向设备推送了一个 4GB 本地 AI 模型，HN 上 1167 票。争议核心不是模型本身，而是浏览器长期拥有的"静默更新权"——过去推几十 MB 安全补丁，现在变成了独立 AI 模型。
🔗 https://www.thatprivacyguy.com/blog/chrome-silent-nano-install/

⑫ Google、Microsoft、xAI 同意让美国政府在发布前审查新模型，Anthropic 未在名单中
三家公司与商务部 CAISI 达成协议，新前沿模型公开前需经政府预部署评估。Anthropic 缺席这一名单值得关注。
🔗 https://www.theverge.com/ai-artificial-intelligence/924017/google-microsoft-xai-government-review

🎙 Podcast

Training Data: Waymo 的 Dmitri Dolgov——2000 万次自动驾驶出行与迈向完全自主的路
Waymo 联合创始人 Dmitri Dolgov 复盘了从 2005 年 DARPA 挑战赛到如今的历程。核心观点：AV 问题的特点是"容易入门，极难收尾"，每次技术潮（CNN、Transformer、LLM）都会重塑曲线前段却不改变长尾。Waymo Foundation Model 是端到端架构，但在标准端到端之上叠加了结构化中间表示，以支持运行时验证、闭环训练和强化学习奖励函数——这是从产品级安全要求倒推出来的架构选择。目前每周行驶 400 万英里，安全事故率比人类司机低 13 倍。
