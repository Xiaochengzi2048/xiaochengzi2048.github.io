🧠 模型

① Claude 正式接入 Microsoft Office 全家桶
Claude for Excel、PowerPoint 和 Word 全面上线付费套餐，Outlook 进入公测。Claude 在不同应用间切换时可以保留完整对话上下文，实现跨 Office 应用的一致体验。这是 Anthropic 进入企业桌面生产力场景的最重要一步。
🔗 https://x.com/claudeai/status/2052445786651168849

② Claude Mythos 帮 Firefox 团队一个月修复了超过过去 15 个月的安全漏洞总量
Anthropic 研究员亚历克斯·阿尔伯特分享：借助 Claude Mythos Preview，Firefox 团队在四月修复的安全漏洞数量超过了过去 15 个月的总和。Mozilla 安全研究员描述发现量为「a wealth of high-severity bugs」，浏览器端首次大批量披露 Mythos 的安全能力产出。
🔗 https://x.com/alexalbert__/status/2052468573516513762

③ Sam Altman：让开发者「宝可梦进化成超级英雄」，比替代他们酷多了

🔗 https://x.com/sama/status/2052485051812909530

🤖 Agent/编程

④ AlphaEvolve 从论文走进 DeepMind 生产线，跑通业务、基础设施、科学三条线
同一个 Gemini 驱动的演化编码 Agent，DeepMind 已将其接入三个性质完全不同的内部领域：业务流程优化、基础设施效率提升和科学算法研究。它不是靠迭代新模型实现的，而是同一套演化架构接管不同问题定义。AlphaEvolve 押注的是 Agent 能持续扩展新任务边界，而非模型版本迭代。
🔗 https://deepmind.google/blog/alphaevolve-impact/

⑤ OpenAI 定义了 Codex 进企业合规栈的最低门槛
OpenAI 一口气发布三份材料：Codex 内部运行手册、客户 Simplex 落地案例、企业 B2B 研究报告。核心是 Agent 接入企业的合规架构——Linux 命名空间隔离、敏感操作走审批、外网默认关闭、Agent 行为单独建遥测层。现有零信任和代码审计体系并不覆盖 Agent 专属遥测，企业得为 Agent 额外建一层访问控制。
🔗 https://openai.com/index/running-codex-safely

⑥ Cursor 设计师：从想法到合并请求，全程在 Cursor 里完成
Cursor 设计师廖睿展示了完整的「从想法到 merge」工作流视频，全部在 Cursor 内完成。展示了编码工具作为设计师日常工具的真实使用场景。
🔗 https://x.com/ryolu_/status/2052496872586272802

⑦ Peter Steinberger：OpenClaw 多 Agent 互相委托，Molty 学会了派发定时任务

🔗 https://x.com/steipete/status/2052630190346457301

⑧ Garry Tan 发布 GStack v1.28，GBrain 新增瘦客户端模式
