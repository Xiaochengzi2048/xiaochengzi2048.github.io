🎙 Podcast

Unsupervised Learning × Latent Space 联合播客（第 85 期）：AI 基础设施是否已趋于稳定？

Redpoint 投资人与 Swyx（Latent Space / Cognition）展开年度对话，覆盖以下核心判断：

**AI 编码战争**：Anthropic 凭借 Claude Code 已达到约 25 亿美元 ARR，OpenAI 与 Cursor 各约 20 亿美元，三家公司在不到一年内共同催生了这个市场。市场结构相对稳定，Gemini 和 xAI 尚未真正进入。

**基础设施是否稳定**：Swyx 认同 Agent Harness 层（skills = 带脚本的 Markdown）趋于共识，但记忆/子代理等维度仍在演化。Harrison Chase 的"终于稳了"不一定准确，但"就算不准，随时跟着变就好"。

**2026 的论断**：2025 是编程 Agent 年，2026 是编程 Agent 冲破边界、吃掉其他一切的年——软件吃掉世界，coding agents 吃掉软件，所以 agents 吃掉世界。

**中等规模创业公司的挑战**：替换 SaaS 比想象的难，团队很难对齐"vibe coding 足够了"的判断；基础设施公司面临"当客户流失时走得极其彻底"的风险。

**企业 AI 的真正买家正在变成 Agent**：Vercel CTO 透露，Vercel 管理控制台 60% 的流量已来自机器人。"如果没有 API，对 Agent 来说你就不存在。"
