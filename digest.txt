🧠 模型

① Claude Opus 4.7 正式发布
Anthropic 正式发布 Claude Opus 4.7，新增 xhigh 努力等级（介于 high 和 max 之间），支持更精细的推理与延迟控制，同时新增 Task Budgets（beta）功能用于长任务成本管理。模型在异步任务执行、UI/文档审美、高清图片处理等方面有显著提升，Claude Code 中默认将 Opus 4.7 的努力等级设为 xhigh。多位开发者表示兴奋，也有人半开玩笑称不得不重写所有代码。
🔗 https://x.com/claudeai/status/2044785272617939282 · https://x.com/alexalbert__/status/2044788914813292583 · https://x.com/_catwu/status/2044815645699928273 · https://x.com/adityaag/status/2044861137720918371

② OpenAI Codex 大幅升级（computer use + 插件 + 主动学习）
OpenAI 对 Codex 进行了重大更新，新增 computer use 功能，可在后台并行使用 Mac 上的所有应用而不干扰用户工作，同时支持应用内浏览器、多款新插件以及主动学习建议功能。kevinweil 称其"出乎意料地好"，levie 认为这代表了知识工作者 Agent 形态的下一个跳跃，可执行起草报告、数据室搭建、文档审阅等长任务。
🔗 https://x.com/sama/status/2044921348540264614 · https://x.com/kevinweil/status/2045004924682195027 · https://x.com/levie/status/2044855448722100720

③ OpenAI 发布 GPT-Rosalind 生命科学前沿模型
OpenAI 推出首个面向科学研究的前沿模型 GPT-Rosalind，专为生物学、药物发现和转化医学设计，内置化学、蛋白质工程、基因组学等领域知识及相关数据库工具。目前正在开放访问申请，并配套上线 Life Sciences 插件。
🔗 https://x.com/kevinweil/status/2045004924682195027

⑤ 构建 eval agent 对主 agent 输出做自动评分
petergyang 分享了一个实用工作流：构建技能时，额外启动一个独立的 eval agent，对主 agent 的输出做 yes/no 判断；若未全部通过则让主 agent 继续迭代，直到满足标准。目前正在将此模式应用于 YouTube 缩略图和标题的自动优化。
🔗 https://x.com/petergyang/status/2045007422084051168
