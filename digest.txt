🤖 Agent/编程

③ Anthropic 发布 Managed Agents：把 AI "大脑"和"双手"彻底解耦
Anthropic 工程博客发布 Managed Agents，一个托管式长任务 Agent 服务。核心思路是把 Agent 的三个组件解耦：session（事件日志）、harness（调度循环）、sandbox（执行环境），任一组件崩溃都可独立恢复。解耦后 p50 首 token 延迟下降约 60%，p95 下降超 90%。同时把凭证从 sandbox 里移走，让 prompt injection 攻不到 token。
🔗 https://www.anthropic.com/engineering/managed-agents

④ Peter Steinberger 发布 Crabbox 0.3.0
OpenClaw 联合创始人 Peter Steinberger 宣布 Crabbox 0.3.0，新增：GitHub 浏览器登录、Blacksmith Testbox 集成、实时 run 回放（crabbox attach）、持久化运行事件、AWS 镜像创建和 Cloudflare Access 支持。同周还更新了 OpenClaw 插件包结构，将大部分功能移入扩展，解决 npm 安装的依赖和启动慢问题。
🔗 https://x.com/steipete/status/2050490163810230579

⑤ Dan Shipper：未来十年工作形态——左侧 Agent 持续运行，右侧人机共用同一应用
Every CEO Dan Shipper 展示了一种未来工作界面：左侧一个持续运行的 Agent，右侧是人和 Agent 共同使用的应用同步进行。他还推荐了 Codex 原生写作应用 Proof 供读者试用。
🔗 https://x.com/danshipper/status/2050583747041640608

⑥ Greg Brockman：OpenAI 内部 Codex 已从写 20% 代码升至 80%
OpenAI 联合创始人兼总裁 Greg Brockman 分享：短短几个月，AI 编程工具在 OpenAI 内部覆盖率从"写 20% 代码"升至"写 80% 代码"。一工程师把复杂系统设计文档交给模型，睡一觉醒来模型不仅实现了初版 spec，还自己加了 instrumentation、跑了 profiler、多次迭代优化到位。他还宣布新工具 Chronicle：插入 Codex，能记录用户所有电脑操作，让模型随时知道上下文。
🔗 https://x.com/sama/status/2050658558174437701

⑦ Aaron Levie：AI 真正大的机会在企业长尾需求

🔒 安全

⑧ AI 急诊诊断准确率超两位医生联合判断，但"调成温和版"后准确率反而下降
哈佛研究在真实急诊病例测试中，至少一个大模型诊断比两位医生联合判断更准。同周另一研究发现：把模型微调成"照顾病人感受"版本后，准确率随即下降——研究者称之为"过度调教"，模型开始把用户满意度凌驾于准确性之上。建议是诊断辅助和患者沟通分开部署两个版本。
🔗 https://ai-digest.liziran.com/zh/digest/2026-05-04-artisan-lifts-this-fine-dog-without-asking-mythos-cyber.html

🎙 Podcast

Training Data: OpenAI 的 Greg Brockman——为什么人类注意力成了新瓶颈
Greg Brockman 在 Training Data 播客谈到，OpenAI 本质上是"买/租/建算力再加价出售"的生意，只要利润为正就值得无限扩规模。他认为 AGI 已完成约 80%，模型在写代码上已超越大多数人类工程师。最值得注意的判断：当前最大的一次性转变不是模型变聪明，而是"让 AI 真正拥有足够上下文"——现在花时间向 AI 解释你在做什么，是一笔值得现在就做的一次性投资。他还透露 OpenAI 内部坚持"必须有人类对合并的代码负责"，不会无条件放权给 Agent。
