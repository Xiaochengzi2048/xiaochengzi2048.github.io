🧠 模型

① Codex 登陆 ChatGPT 手机端
Sam Altman（OpenAI 首席执行官）宣布 Codex 正式进入 ChatGPT 移动端（iOS/Android）。最初 Codex 只有桌面版，手机版让开发者可以远程连接到运行 Codex 的机器，随时查看输出、审批改动、启动新任务。和 Anthropic 的 Claude Code 正面竞争进入白热化。
🔗 https://x.com/sama/status/2055034461591588916

② OpenAI 重组，Greg Brockman 统管全部产品，全押 Agent
Sam Altman 同日发推提及一系列内部变化，内部备忘录明确今年战略"全押 AI Agent"，Greg Brockman 正式接管所有产品线。这是 OpenAI 本轮从工具到 Agent 平台转型的最直接信号。
🔗 https://x.com/sama/status/2055034714231345475

③ xAI 正式退役旧版 Grok，全面切换到 Grok 4.3
5 月 15 日，xAI 退役多个旧版 Grok 模型，所有流量统一走 Grok 4.3——支持无/低/中/高四档推理强度。同期上线的还有语音 API（Grok Voice Think Fast 1.0）、自定义声音克隆、以及更高画质的图像生成 API。
🔗 https://docs.x.ai/developers/migration/may-15-retirement

🎙 Podcast

The MAD Podcast with Matt Turck: Why Every AI Agent Needs Its Own Computer | Ivan Burazin (Daytona)
Ivan Burazin 是 Daytona（agent 沙箱基础设施初创公司）的 CEO，这期播客从第一原理出发探讨：为什么 Agent 需要自己的电脑？Ivan 的核心论点是：每个 Agent 至少需要一个沙箱，有时候需要多个——就像知识工作者必须有电脑才能工作。当他尝试让 Claude 直接访问公司银行账户时，发现这个假设根本行不通；必须给 Agent 配备独立的机器。他还拆解了完整的 Agent 技术栈：模型、沙箱、工具、MCP、记忆、编排，以及为什么 Daytona 最终放弃 Kubernetes 自己写调度器。
🔗 https://www.youtube.com/watch?v=kMXJrzAa5fM
