① Claude Code 正式支持云端多 Agent 管控
Cat Wu（Anthropic Claude Code 核心团队）宣布 `claude agents` 命令上线，在终端启动一个控制面板，可统一管理所有本地及云端 Claude Code 进程。在任意命令行会话里按 `←` 箭头就能把该 session 注册进控制面板，方便从根代码目录集中调度多路 Agent。

🔗 https://x.com/_catwu/status/2053873949646405879

③ Karpathy：让 LLM 输出 HTML，直接浏览器查看效果更好
Andrej Karpathy 分享了一个实用技巧：在提示末尾加上"请把回答组织成 HTML 格式"，然后在浏览器里打开生成文件，可视化效果明显优于纯文本。他认为音频是人类偏好的 AI 输入方式，但 HTML/幻灯片输出是信息展示的更优出口。
🔗 https://x.com/karpathy/status/2053872850101285137
