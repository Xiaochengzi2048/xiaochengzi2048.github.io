④ Agents 的原生语言是 HTML，不是 XML
Zara Zhang（前谷歌，开发者工具构建者）发现：让 AI Agent 生成 HTML 幻灯片比生成 XML 幻灯片效果好得多。她认为"Agent 用 HTML 表达自己"——这个观察对于需要 Agent 生成可视化输出的工程师有很强的实践价值。
🔗 https://x.com/zarazhangrui/status/2046454622852657264

⑤ Dan Shipper：双 Agent 协作效果更好
Every 创始人 Dan Shipper 在实验后得出结论：两个 Agent 协同工作比单个 Agent 效果更好。这条推文引发了大量讨论（40 条回复），反映出业内对多 Agent 架构的持续关注。
🔗 https://x.com/danshipper/status/2046231280430240141

⑥ Aaron Levie：企业需要专职 Agent 工作流负责人
Box CEO 亚伦·利维指出，从聊天机器人升级到真正自动化流程需要大量工程和组织投入。他建议企业设立专门负责"落地 Agent 自动化"的岗位，而不是让每个员工自行摸索，原因是技术复杂度和侧项目推进模式都行不通。
🔗 https://x.com/levie/status/2046397816755634340
