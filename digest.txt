① 谷歌 Lyria 3 音乐生成 API 全球开放
谷歌向全球开发者开放 Lyria 3 音乐生成付费预览，通过 Gemini API 接入。支持 Pro 版本生成最长 3 分钟完整歌曲，Clip 版本生成 30 秒片段。用户可通过自然语言指定节奏、歌词、段落结构，支持多语言演唱和图像输入推断风格。训练数据来自 YouTube 授权素材，输出嵌入 SynthID 水印，不模仿特定艺术家。
🔗 https://ai-digest.liziran.com/zh/

② OpenAI 公布 agent 漏洞赏金计划与安全工具
OpenAI 单日发布三项安全举措：推出 Safety Bug Bounty 计划覆盖提示注入、数据外泄等 agent 漏洞，发布公开的 Model Spec 文档规定模型在安全与用户自由间的取舍原则，发布 gpt-oss-safeguard 开源工具供开发者调用年龄相关内容审核。这是业界首例专门针对 agent 漏洞的赏金计划。

📚 论文速报

① OmniAgent（arxiv 2606.19341）：将多模态感知建模为 POMDP 循环，选择性观看视频帧而非处理所有帧。7B 模型在 LVBench 上达 50.5%，超越 Qwen2.5-VL-72B 的 47.3%，展现推理的正向扩展性。
🔗 https://arxiv.org/abs/2606.19341

② RNG-Bench：通过多轮感知任务发现记忆是多模态 agent 的瓶颈，而非决策能力。大多数失败源于遗忘之前的观测。提出记忆间隙度量分离"遗忘"与"决策失败"。
🔗 https://arxiv.org/abs/2606.19338

③ Sumi（arxiv 2606.19005）：首个大规模开放均匀扩散语言模型，7B 参数 1.5T token，完全开放权重、检查点、配方和数据混合。在知识、推理、编码上与自回归相当，展示扩散 LM 的可行性。
🔗 https://arxiv.org/abs/2606.19005

④ LoopCoder-v2：两层循环架构将 SWE-bench 成绩从 43% 提升至 64%，展现代码生成的新方向。
🔗 https://arxiv.org/abs/2606.19
