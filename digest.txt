🧠 模型

① OpenAI 发布 Claude 代码自动模式（Auto Mode）
Anthropic 工程团队推出 Claude Code 的 auto mode，用双层分类器替代人工审批：输入层扫描提示注入，输出层在执行前拦截危险操作。在内部 1 万条真实流量中误判率仅 0.4%，但对真实越权行为的漏检率达 17%——团队坦承这是设计取舍，适合从 --dangerously-skip-permissions 迁移的用户，而非高风险基础设施的替代品。
🔗 https://www.anthropic.com/engineering/claude-code-auto-mode

② Sam Altman：是时候重新设计操作系统和用户界面了
奥尔特曼在推文中表示，"现在是认真重新思考操作系统和用户界面设计的好时机"，并指出互联网协议应该同等适用于人和 Agent。这条推文获得 1 万次点赞，反映出业界对"人机共用 OS"这一方向的高度关注。
🔗 https://x.com/sama/status/2048428561481265539

③ Sam Altman 发布 OpenAI 五项核心原则
奥尔特曼在推文中公开了 OpenAI 的五条指导原则：民主化、赋权、普遍繁荣、韧性、适应性。发布时机恰在 GPT-4.5 受到开发者热烈反响之后，有意强化公司在 AGI 时代的价值叙事。
🔗 https://x.com/sama/status/2048552677433643427

🤖 Agent/编程

④ Guillermo Rauch：编程 Agent 是所有超级智能的基础
Vercel CEO 拉乌赫发文称，编码能力实质上等同于"对计算机的精通"，而 Agent 的独特之处在于能够检视自身源码、状态和指令，甚至提出对自身的修改。他认为"我无法创造的，我便无法理解"——编程流畅度让模型对所有计算机工作有了更深的理解。
🔗 https://x.com/rauchg/status/2048523195305902341

⑤ Peter Steinberger 发布 birdclaw：本地推文存档工具
Steinberger 开源了 birdclaw，一个将 X 推文存档本地、备份到 GitHub 并支持每日导入书签的工具（因 X API 不完整开放书签接口，通过定时任务绕过）。这条推文获得 727 个点赞，是当日最高互动内容之一。
🔗 https://x.com/steipete/status/2048626844694421842

⑥ Peter Steinberger 发布 wacrawl 0.2.0：加密备份 WhatsApp 存档
wacrawl 新版本支持将 WhatsApp Desktop 存档加密后推送到 GitHub（age 加密分片），并支持本地拉取解密恢复，为个人数据自主权提供了一个实用工具。
🔗 https://x.com/steipete/status/2048660875007914176

⑦ Peter Steinberger：用 Blacksmith 解决 OpenClaw 测试的 CPU 瓶颈
Steinberger 分享了将 OpenClaw 本地测试迁移到 Blacksmith 云端的经历，Codex 可以调用最多 32 核实例并发跑测试套件，显著加速了开发迭代。

⑧ Peter Yang：为自己的健身应用构建 MCP Server
Peter Yang 周末为自己的移动健身应用添加了 MCP 服务器支持，可以通过 Claude/Codex 等获取最新训练数据或更新训练计划。他称"这太好玩了"——体现出 MCP 协议正在被创业者用于打通自有应用与 AI 助手。
🔗 https://x.com/petergyang/status/2048611053333041158

⑨ Garry Tan：构建个性化 Agent 的三文件体系
YC 合伙人陈嘉兴分享了他的个人 Agent 文件架构：SOUL.md 定义 Agent 的声音与价值观（约等于"宪法"），USER.md 深度建模用户本人（他的版本约 4000 字），AGENTS.md 是操作规则手册。他强调"越具体越有生命力，通用指令只能产出通用输出"。
🔗 https://x.com/garrytan/status/2048669695344046090

📈 商业/观点

⑪ Aaron Levie：AI 时代的"盖尔-曼失忆症"变体
Box CEO 莱维观察到一种新的认知偏差：人们用 AI 处理自己的工作时，深知最后一公里有多少人工干预；但看别人的工作时，却轻易认为 AI 能完全自动化。他认为这种"只对自己工作有深刻同情"的视角，是目前许多岗位替代预测被高估的重要原因。
🔗 https://x.com/levie/status/2048576989930619185

⑫ Aaron Levie：Agent 时代的两种"过度工作"陷阱
莱维指出当前从业者普遍超时工作的两个结构性原因：一是 Agent 的杠杆感让人像管理团队一样感到"任何空闲都是浪费"；二是 AI 极大降低了启动成本，导致人们启动了远比以往更多的项目，却在最后 10% 耗费大量时间。他认为这不可持续，但会催生大量从实验升级为正式产品的机会。
🔗 https://x.com/levie/status/2048537503972684252

🎙 播客

AI & I by Every：《专为 LLM 无法完成之事而生的 AI 模型》
创始人 Eve（Logical Intelligence CEO）解释了能量基础模型（EBM）与 LLM 的核心区别：EBM 不依赖 token 预测，而是通过能量景观直接建模数据的规律，天然支持可约束、可验证的推理。她认为把所有任务都压进语言空间"感觉真的很不对"，而 EBM 在空间推理、硬件验证、形式化代码生成等任务上有结构性优势。这个模型叫 Kona，正式名称是"带潜变量的能量推理模型"。
🔗 https://www.youtube.com/watch?v=Q-i8ZSUCtIc
