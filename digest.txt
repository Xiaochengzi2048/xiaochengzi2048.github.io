🤖 Agent/编程

③ Claude Code 团队在猎杀「大文件写入卡住」的顽固 bug
Anthropic Claude Code 团队成员 Thariq 在推文中说，Claude Code 在处理大文件写入时偶尔挂起的 bug 已被定位，这是他个人追踪已久的白鲸级问题。与此同时他提到团队正在把「无闪烁渲染器」做成默认选项，相关更新即将推出。
🔗 https://x.com/trq212/status/2049252080892973563

④ Peter Steinberger：在每次代码合并时自动跑 Codex 审查
Peter Steinberger（OpenClaw 创始人，现 OpenAI）在 OpenClaw 上部署了一套自动化流程：每次有代码合并到主分支，就自动触发一个 Codex 实例做 review，发现问题后再自动生成修复 PR，之后再跑一个 review agent，最多循环 5 轮。上线 10 分钟就抓到了他自己提交的一个 bug。
🔗 https://x.com/steipete/status/2049356949523730699

⑤ Dan Shipper：在 Codex 浏览器里集成 PostHog，agent 与人共享数据视角
Every 的 Dan Shipper 分享了一个工作流：把 PostHog 内嵌到 Codex 的内置浏览器，让 Codex 直接写查询并看结果，还能从里面触发其他 agent 去写 PR 或跑生产数据库查询。他由此提出「Codex-native / Cursor-native」这个概念——专门为 agent 内置浏览器设计的软件，是下一波产品机会。
🔗 https://x.com/danshipper/status/2049236793761976357

⑥ Vercel Labs 招人：从为人类造工具，转向为 agent 造工具
Vercel CEO Guillermo Rauch 宣布 Vercel Labs 正在扩招，使命是构建 AI 时代的开发工具。他列出已上线的 agent 向工具：agent-browser、portless、skills、chat、just-bash、json-render，累计下载量超过 2280 万。
🔗 https://x.com/rauchg/status/2049216048831025232

⑦ Peter Yang 发现了一个适合个人 agent 的绝妙设计
Roblox 产品主管 Peter Yang 转发了一个适合个人 agent 的设计，称已经搬进他的 OpenClaw。他同时感慨：独立 AI 建设者越来越让人敬佩，「世界现在是他们的操场」。
🔗 https://x.com/petergyang/status/2049347897310003443

⑧ Zara Zhang：用 AI 生成 SVG，而不是光栅图
Zara Zhang 展示了在 AnyGen 前端幻灯片功能里用 QuiverAI 接口生成 SVG 插图的工作流，认为矢量插图比光栅图更适合嵌进 HTML 幻灯片设计。她另外评论了「把 app 变成 GitHub 仓库」的趋势：用户的 agent 自己去定制界面。
🔗 https://x.com/zarazhangrui/status/2049258231042805806

📈 商业/观点

⑪ Aaron Levie：软件工作不会消失，agent 会让软件总量扩大 100 倍
Box 的 Aaron Levie 发了一篇论证密度颇高的长文：他认为 agent 不是从现有蛋糕里切走份额，而是在扩大蛋糕本身——遗留系统重构、中小企业首次能用上开发者、安全漏洞修复，加在一起是百倍于当前的软件量。他也承认：对想快速做一个要自己维护的复杂软件的普通人，Agentic coding 帮助有限，升级维护是大多数人没准备好承担的税。
🔗 https://x.com/levie/status/2049333853777764495

⑫ Garry Tan：2026 年是 agent 话题的「永恒九月」
YC 总裁 Garry Tan 调侃说，如果你已经听烦了 agent，2026 年对你来说就是「永恒九月」。他转发了关于 AlphaGo 十周年的内容，感叹「十年了，真不可思议」。
🔗 https://x.com/garrytan/status/2049351894007710031

⑬ GitHub 免费服务承压，Amjad Masad 建议引入比特币微支付
Replit CEO Amjad Masad 评论了 GitHub 在 AI bot 流量激增下仍维持服务的努力，并重申预测：免费服务在人形机器人普及后将难以为继。他提议用比特币驱动的微支付（每次 git push 几美分）既能减少垃圾流量，又不需要 KYC，保留开放性。
