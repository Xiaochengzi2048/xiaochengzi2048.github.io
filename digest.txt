🔒 安全

① Vercel 遭受 AI 加速的供应链安全攻击
Vercel 首席执行官 Guillermo Rauch 披露：一名员工账号因使用的某 AI 平台（Anon.ai）被入侵，攻击者借此渗透到 Vercel 的 Google Workspace，进而枚举非敏感环境变量，获取更深层访问权限。Rauch 判断攻击者"极具针对性，极有可能被 AI 大幅加速"，移动速度和对 Vercel 内部结构的理解令人警惕。目前受影响客户数量"非常有限"，Vercel 已推送安全公告，建议所有用户轮换密钥并审查环境变量权限。
🔗 https://x.com/rauchg/status/2045995362499076169

② 网络安全公司将因 AI 驱动攻击浪潮大幅升值
FPV Ventures 合伙人 Nikunj Kothari 指出：模型能力提升会持续加快攻击频率，人类依然是最主要的攻击入口，而眼下看到的一切还只是开始。Vercel 事件恰好印证了这一判断。
🔗 https://x.com/nikunj/status/2046007615512256624

🤖 Agent/编程

③ 开发者吐槽 OpenClaw 接 GPT 模型后 Agent 能力大幅下滑
Product at Roblox 的 Peter Yang 花一小时以上尝试让 OpenClaw 配合 GPT 完成定时邮件任务，结果连 Claude Opus 轻松搞定的工作都无法完成，收到一堆"你把模板搞乱了"的错误响应。他认为这不是个例——他所在的多个 AI builder 社群有类似反馈，期待 GPT-5.5（代号 Spud）能解决 Agent 跟随问题。
🔗 https://x.com/petergyang/status/2046036593199497615

④ Garry Tan 用 Claude Code 持续迭代自己的开源工具集 GStack
YC 总裁 Garry Tan 发布 GStack v1.4，新增 `/make-pdf` 技能，可与 OpenClaw/Hermes 及 Claude Code 直接集成使用。他的工作流是：在自己的 agent 使用中遇到需求 → 让 Claude Code 实现 → 开源发布。他也建议遇到 cron/subagent 问题的用户，让 OpenClaw 自己用工具实现替代方案，等待更好的插件 API 成熟。
🔗 https://x.com/garrytan/status/2046097059057651941

⑤ 工具越来越强，产品团队应把时间从内部沟通转向用户沟通
Zara Zhang 观察：AI 擅长执行，所以人类应专注于"搞清楚要做什么"，而这需要和外部用户深度交流才能迸发灵感。她看到一些独立开发者的模式：整天和用户谈话，录音扔给 agent，由 agent 来决策并执行。团队规模变小，内部协调开销骤降，这一趋势已经在实际 agent 重度团队中发生。
🔗 https://x.com/zarazhangrui/status/2045810170245386713

📈 商业/观点

⑥ AI 工具不会消灭工种，而会推高每个工种的复杂度门槛
Box CEO Aaron Levie 认为"AI 取代今天的工作"是个静态市场谬误。当所有人都用上同等工具，市场会自动重新校准，工作的定义随之上移：写合同摘要不再是律师助理的核心职责，剪辑视频不再是视频编辑的壁垒。懂行的工程师配上 AI，远比不懂行的人用 AI 产出更高——专业判断依然是核心差异。
🔗 https://x.com/levie/status/2046067263326028108

⑦ 软件正在从无服务器走向"无头"——尽职调查面临挑战
FirstMark 风险投资人 Matt Turck 半开玩笑地指出：软件先去掉了服务器，现在又在去掉"头"，留给投资人做尽调的东西越来越少了。调侃之下是对软件形态加速抽象化的真实观察。
🔗 https://x.com/mattturck/status/2045987462409826604

⑧ 对 AI 实验室的真诚度，你最信任哪家？
Linear 产品负责人 Nan Yu 抛出一个问题：如果各大实验室同时发布新闻稿，你觉得哪家说的和心里想的距离最近？没有给出答案，但问题本身颇具针对性。
🔗 https://x.com/thenanyu/status/2045910980597530836

🎙 Podcast

Unsupervised Learning：OpenAI 首席科学家谈持续学习、强化学习与对齐方向
嘉宾 Ako Paioki（OpenAI 首席科学家）与主持人深入探讨了三个核心问题：一、持续学习是当下研究的真实路径，而非被忽视的议题，是 OpenAI 正在推进的方向；二、编程工具的爆发是模型进展的重要信号，OpenAI 内部绝大多数编码工作已切换到 Codex；三、对齐的长期挑战在于泛化——模型在陌生场景下究竟会回退到什么价值观。他还谈及 AI 在数学和物理研究中的进展，以及到 2028 年实现"完全自动化 AI 研究员"的路线图。
