🤖 Agent/编程

③ "HTML 是新 Markdown"：Claude Code 输出约束实验刷屏
Anthropic Claude Code 工程师 Thariq 发布博文《Using Claude Code: The Unreasonable Effectiveness of HTML》，核心结论：把 Claude Code 的输出格式约束为 HTML，原型开发能力会暴增。这条推文获得 8700 个赞、671 转发，Simon Willison 转发后挂上 HN 头版拿到 396 分，评论区围绕"为什么是 HTML"激烈讨论。

④ Steipete：给 Codex 的技能越多，提示词写得越少

🔗 https://x.com/steipete/status/2052971550966440251

⑤ Zara Zhang：用 OpenAI Realtime 2 API 构建 YouTube 实时副驾驶

⑥ Garry Tan：个人软件时代即将到来

🔒 安全

⑦ Amanda Askell：对齐研究的正向愿景
Anthropic 哲学家兼伦理研究员 Amanda Askell 发文指出，对齐研究不只是关于"防止坏行为"，更重要的是给模型和训练过程一个诚实而积极的愿景——让 AI 成为什么、为什么这样做。她表示对这个方向的未来感到兴奋。

📈 商业/观点

⑧ Aaron Levie（Box 创始人）：企业智能体的 token 预算管理将成为大问题
Box 创始人 Aaron Levie 观察到一个新趋势：大企业开始把 token 用量当成正式预算项目来管理，就像分配人力或营销费用一样。智能体能做越来越长的任务，跨团队的 token 分配将成为真实的运营决策，而非技术问题。
🔗 https://x.com/levie/status/2052903105256382679

⑨ Matt Turck（FirstMark）：AI 智能体的定价逻辑不一定纯粹按消耗量
VC 投资人 Matt Turck 指出，智能体定价未必会走纯消耗（token 计量）模式。企业智能体需要身份、角色、授权、预算、审计日志等能力，听起来更像"席位（seat）定价"——只不过不是人类席位，而是智能体席位。
🔗 https://x.com/mattturck/status/2052839798063112303

⑩ Dan Shipper（Every 创始人）：Milken 会议的人比 AI 圈子落后三到四个月
Every 创始人 Dan Shipper 在 Milken 全球会议后发帖：台上讨论的 AI 话题明显滞后，而 Codex 再过几个月就会让所有人惊呼。他认为这种时间差是一个投资机会。
🔗 https://x.com/danshipper/status/2052865144066097217

🎙 Podcast

AI & I by Every：Claude 平台团队揭秘构建逻辑
Anthropic Claude 平台产品负责人 Angela 和工程负责人 Caitlin 接受 Every 采访，揭示了平台演进的完整逻辑。核心观点：多数人以为"最难的是提示词工程"，实际上把原型推上生产环境的基础设施才是真正的墙——这也是 Claude Managed Agents 诞生的原因。她们还预判未来的平台将向更高阶抽象演进：由 Claude 自己决定应该使用哪个模型、如何启动子智能体，用户不再需要手动配置智能体架构。团队希望把 Slack bot、多智能体协作等场景做成一键部署的体验。

📚 论文速报（来源：ai-brief.liziran.com · 2026-05-08）

① T²PO（ICML 接收）：多轮智能体强化学习的崩溃不是信用分配问题，而是要用模型自身的不确定性触发重采样，在 WebShop、ALFWorld、Search QA 上显著改善稳定性。
② PhysicianBench：100 个真实 EHR 医疗咨询场景，平均每次任务调用 27 个工具；最佳闭源模型通过率 46%，最佳开源模型仅 19%。医疗智能体离临床可用仍有很大距离。
③ MotionCache：像素级视频生成缓存，按帧差异为每个像素分配去噪步数；在 SkyReels-V2 上实现 6.28 倍加速，在 MAGI-1 上仅 1.64 倍，差异揭示了不同视频生成架构的缓存友好度差别。
