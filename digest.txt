🧠 模型

① Goodfire 发布 Silico：首次把「打开模型调参数」做成开发者工具
旧金山初创 Goodfire 推出 Silico，允许工程师在训练过程中直接窥视模型内部，定位决定行为的具体参数并进行细粒度调整。这种可解释性干预能力此前只在 OpenAI、Anthropic 等顶级实验室内部使用。背景是 GPT-5 上线后出现「哥布林模式」怪癖，OpenAI 本周首次公开溯源到训练数据中某批特定来源——而 Silico 瞄准的正是这类生产环境人格漂移问题，工程团队不必靠重训练或 prompt 补丁，训练过程中就能介入。
🔗 https://ai-digest.liziran.com/zh/digest/2026-05-01-musk-admits-xai-trained-grok-openai-models-zig-bans-ai.html

② Anthropic 新一轮融资估值或破 9000 亿美元
据 TechCrunch，Anthropic 要求投资人在 48 小时内提交认购额度，新一轮融资可能两周内完成。继 Google 追加最高 400 亿美元投资后，Anthropic 估值锚点再度上移。
🔗 https://techcrunch.com/2026/04/30/anthropic-potential-900b-valuation-round-could-happen-within-two-weeks/

③ Mistral 发布 Medium 3.5 及远程 Agent 功能
Mistral 本周上线新模型 Medium 3.5，同步推出「vibe remote agents」功能，进一步扩展其在欧洲主权 AI 赛道的产品矩阵。
🔗 https://mistral.ai/news/vibe-remote-agents-mistral-medium-3-5

④ 智谱发布 GLM-5V-Turbo 多模态 Agent 基础模型
新模型将多模态感知整合进推理、规划、工具使用全流程，覆盖图像、视频、网页、文档、GUI 等异构输入，面向多模态 agent 应用场景。
🔗 https://huggingface.co/papers/2604.26752

🤖 Agent/编程

⑤ Zig 项目宣布拒收 AI 写的代码贡献
Zig 维护团队明确把 AI 生成代码挡在贡献入口外。理由不是反 AI，而是没经人类深度理解就提交的 PR 会让维护者长期背锅 debug。Simon Willison 转述后引发大量讨论，社区共识是「贡献门槛要重新立规则」。
🔗 https://ai-digest.liziran.com/zh/digest/2026-05-01-musk-admits-xai-trained-grok-openai-models-zig-bans-ai.html

⑥ GitHub Copilot 把 AI 代码评审拆出来按分钟计费
从 6 月 1 日起，Copilot 的代码评审功能从订阅中剥离，按每分钟从团队 GitHub Actions 额度中扣费。已付月费的团队每次 AI 评审也要单独算账——AI 辅助开发「默认免费」的时代开始终结。
🔗 https://ai-digest.liziran.com/zh/digest/2026-05-01-musk-admits-xai-trained-grok-openai-models-zig-bans-ai.html

⑦ Stripe 推出 Link 数字钱包，AI Agent 可直接完成支付
用户绑定银行卡和订阅后，可授权 agent 通过审批流自动完成支付。Stripe 同期发布了与 OpenAI 共建的 Agent-to-Commerce 协议（ACP），商户只需接一次 Stripe 即可向 ChatGPT、Microsoft Copilot、Meta 等主流 AI 渠道开放购买流程，merchant 仍是交易方，不交出客户关系和反欺诈控制权。
🔗 https://techcrunch.com/2026/04/30/stripe-link-digital-wallet-ai-agents-shopping/

⑧ OpenAI Codex 周活突破 400 万，进驻埃森哲等咨询巨头
OpenAI 本周公布 Codex 的 400 万周活数据，并宣布推进 Accenture 等大型咨询公司的企业部署。Anthropic 同期公开了 Claude Code 降质事件 postmortem，透明度高于以往。
🔗 https://ai-digest.liziran.com/zh/digest/2026-04-24-openai-offers-25000-crack-gpt-55s-bio-guardrails-codex-hits.html

🎙 Podcast

AI & I by Every：How Stripe Is Building for an Agent-native World
Stripe 数据与 AI 负责人 Emily 接受采访，分享了 Stripe 对 Agent 经济的判断。核心观点：互联网正在从「人类主导的交易」转向「Agent 是主要参与者」的新阶段，Stripe 正在从反欺诈、支付基础设施、定价模型三个维度全面重构。数据点值得关注：AI 公司欺诈攻击中「多账号滥用」占注册量约 7%，头部 AI 公司每周拦截 25 万个欺诈免费试用；LLM 流量对 Stripe 文档的访问量同比增长 10 倍。对于 AI 公司定价趋势，Emily 预判：模型提供商会留在按 token 计费，垂直解决方案长期会走向「按结果计费」，传统按席位收费在 B2B 场景将快速消亡。
