🗞 AI Builders 日报 · 2026.05.14

🧠 模型

① GPT-5.5 Instant 成为默认模型，幻觉率降低一半
OpenAI 将 GPT-5.5 Instant 升级为 ChatGPT 所有用户的默认模型，高风险任务幻觉率比上一版下降 52.5%。与此同时 GPT-5.5 API 正向企业客户滚动开放，另有安全专项版本 GPT-5.5-Cyber 在网络安全团队中小范围预览。OpenAI 当前年化收入已达 250 亿美元。
🔗 https://www.distillintelligence.com/briefings/ai-leaders-2026-05-08

② 谷歌 Android 发布会抢在 I/O 前一周拉满预期
谷歌 5 月 12 日举办"Android Show"，正式推出 Gemini Intelligence 品牌——在 Android 手机、手表、车机、眼镜、笔记本上跑跨应用多步代理（比如读菜谱自动下单买菜）。同步宣布与华硕、戴尔、惠普、联想、宏碁合作打造"Googlebooks"AI 原生笔记本，秋季上市。谷歌 I/O 2026 定于 5 月 19-20 日，官方自称"史上 AI 含量最高"。
🔗 https://techcrunch.com/2026/05/12/everything-google-announced-at-its-android-show-from-googlebooks-to-vibe-coded-widgets/

③ Claude Opus 4.7 在华尔街发布，附带 10 个金融 Agent
Anthropic 在与摩根大通联合举办的活动上推出 Claude Opus 4.7，并配套上线 10 个面向金融场景的 AI 代理（能写投资备忘、做信贷分析），可通过 Claude Code 和 Claude 托管代理插件使用。Claude Sonnet 4.6 同期被评为真实世界代理基准测试第一名。
🔗 https://releasebot.io/updates/anthropic/claude

④ Grok 4.3 API 上线，百万上下文窗口
xAI 发布 Grok 4.3 API，支持百万 token 上下文窗口，官方称代理工具调用排名全球第一，并上线写实图像生成接口。同期传出 xAI 将与 X 整合并以"SpaceXAI"品牌重组的消息。
🔗 https://www.distillintelligence.com/briefings/ai-leaders-2026-05-08

⑤ Mistral 发布 1280 亿参数旗舰模型
Mistral 推出迄今最大模型 Mistral 128B，并在 Le Chat 中上线异步云端编程的"Work"代理模式。Mistral 完成新一轮融资后估值约 140 亿美元，荷兰光刻巨头 ASML 为最大股东，是欧洲最具代表性的前沿 AI 公司。
🔗 https://aitoolsrecap.com/Blog/MayNews2026.aspx

🤖 Agent/编程

⑥ Claude Code 推出"自动模式"，在权限安全上找到中间路
Anthropic 工程团队发布博客，介绍 Claude Code 新增的 Auto Mode：用模型分类器代替人工审批——既不是每步都弹窗确认（93% 的确认其实是无效点击），也不是完全跳过权限检查。该模式专门用于拦截"越权行为"（如误删远程分支、上传 GitHub Token 到内部集群）。文中提到这类问题已有内部事故记录在案，Claude Opus 4.6 系统卡中也有详细说明。
🔗 https://www.anthropic.com/engineering/claude-code-auto-mode

⑦ Anthropic 租下 SpaceX Colossus 超算，22 万张 GPU 上线
Anthropic 确认租用马斯克旗下 SpaceX 的 Colossus 1 超算，新增逾 300 兆瓦算力和 22 万张英伟达 GPU。随即宣布 Claude Code 在 Pro、Max、团队和企业各档次的速率限制全线翻倍。另有 15 亿美元企业服务合资公司（与黑石、高盛合作）及 Akamai 18 亿美元云合同同步曝光。
🔗 https://aitoolsrecap.com/Blog/ai-news-may-10-2026

⑧ 谷歌"涂鸦"主页小组件：用自然语言生成安卓桌面组件
谷歌在 Android Show 上演示了"Vibe-coded Widgets"——用户用自然语言描述需求，Gemini 直接生成定制化主屏幕组件。Chrome 安卓版同步集成 Gemini，可对页面内容提问；Gboard Rambler 则用 Gemini 做语音转文字的后处理清洗。
🔗 https://9to5google.com/2026/05/12/the-android-show-2026/

🔒 安全

⑨ 美国政府与科技巨头签署 AI 预发布审查协议
特朗普政府改变立场，商务部与微软、谷歌、xAI 等达成新协议，要求主要实验室在新前沿模型发布前接受政府预审。这是美国 AI 治理的重大转向，意味着前沿模型上市前要经政府过目。
🔗 https://www.nytimes.com/2026/05/04/technology/trump-ai-models.html

📈 商业/观点

⑬ Anthropic 年收入增长 80 倍，估值冲刺 9000 亿美元
Anthropic CEO 达里奥·阿莫代（Dario Amodei）披露，一季度收入同比增长 80 倍，年化收入达 440 亿美元，并于 5 月初超越 OpenAI 成为收入最高的 AI 公司。年消费超百万美元的客户从两年前的约 12 家增至 500 多家，主要驱动力是 Claude Code 和与摩根大通联合开发的金融代理。新一轮融资估值目标 9000 亿美元。
🔗 https://aitoolsrecap.com/Blog/ai-news-may-11-2026

⑭ Anthropic 被踢出五角大楼合同，诉诸法院后获胜
五角大楼与 SpaceX、OpenAI、谷歌、微软等签署 AI 合同，唯独将 Anthropic 排除在外——理由是特朗普政府将其列为"供应链风险"。Anthropic 拒绝提供用于自主武器和大规模监控的 Claude，并在旧金山和华盛顿同时起诉，加州联邦法官已裁定阻止政府排除行为。阿莫代与白宫幕僚长会谈后，双方称"富有成效"。
🔗 https://aitoolsrecap.com/Blog/ai-news-may-11-2026

⑮ 马斯克诉阿尔特曼庭审：穆拉蒂作证称阿尔特曼撒谎
马斯克与 OpenAI/山姆·阿尔特曼（Sam Altman）之间的诉讼庭审持续发酵：前首席技术官米拉·穆拉蒂（Mira Murati）作证称阿尔特曼就新模型安全标准对其撒谎；格雷格·布罗克曼（Greg Brockman）日记作为证据呈庭；检方指控阿尔特曼制造"混乱和不信任"。马斯克的动机被披露为"用 OpenAI 控制权资助火星城市"，OpenAI 与 Anthropic 曾有过接近合并的谈判也随之曝光。
🔗 https://www.distillintelligence.com/briefings/ai-leaders-2026-05-08

🎙 播客

Training Data（红杉资本出品）：Waymo 联合创始人——2000 万次出行与自动驾驶的长期主义
Waymo 联合创始人德米特里·多尔戈夫（Dmitri Dolgov）在红杉峰会分享近 20 年打磨自动驾驶的心路历程。他强调：自动驾驶不是算法问题，是"量产可靠性"问题，要在最坏的天气和最复杂城市场景中持续积累数据。Waymo 已完成 2000 万次商业载客，日活用户覆盖现场嘉宾大半。他认为短期全无人化驾驶的关键瓶颈不是技术，而是监管和规模化运营效率。
