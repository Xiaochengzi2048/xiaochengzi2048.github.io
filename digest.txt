📚 论文速报
（来自 ai-brief.liziran.com）

① Arbor：通过假设树自动完成完整研究循环，MLE-Bench Lite 任务达成 86.36% 中奖率
持续协调器 + 一次性执行器隔离工作树的架构设计，相比 Codex 和 Claude Code 平均提升 2.5 倍。关键洞察在于记忆结构（而非单次推理能力）决定长视野 Agent 的上限。
🔗 https://arxiv.org/abs/2606.11926

② RACES：递归环境组合引擎，50 个基础环境相当于 300 个独立环境的训练价值
通过 SEQUENTIAL、PARALLEL、SORT、SELECT 操作符将可验证环境当作 LEGO 积木组合，环境工程成为新的扩展轴。14B 模型在 6 个未知基准上平均获得 +3 分。
🔗 https://arxiv.org/abs/2606.12373

③ InternVideo3：长视频 Agent 理解，观察、推理、工具、记忆共享一个演化上下文
M²LA 令牌保留注意力重参数化压缩 KV 缓存，训练路径从预训练 → 短长视频微调 → 基于规则的强化学习 → 策略蒸馏。
🔗 https://arxiv.org/abs/2606.12195

④ Bebop：修复强化学习中 MTP 接纳度下降问题，训练加速 1.8 倍
MTP 接纳度与模型熵呈负相关，通过概率拒绝采样 + 电视损失直接优化接纳度，可达 95% 接纳率且无需在线更新。
🔗 https://arxiv.org/abs/2606.12370

⑤ ICA Lens：无需训练 SAE 的解释性方法，激活几何中提取可读方向
从激活几何独立提取可读方向（无逐层梯度训练），SAEBench 稀疏探针与公开 SAE 相当，定向探针性能优于小中型预算。
🔗 https://arxiv.org/abs/2606.11722
