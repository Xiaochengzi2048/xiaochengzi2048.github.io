⑤ Peter Yang：AI 「slop 复利」陷阱
彼得·杨（Peter Yang）描述了一种常见陷阱：先让 AI 生成 markdown 文件，懒得改，之后再让 AI 用这些文件生成新文件，slop 比例从 5% 滚到 10% 再往上，最后一堆没人真正理解的文件堆成山。他自己也承认懒得手动改 agent 生成的文件，觉得用户体验上还有欠缺。另外他还提到 Claude Code 有时沉默挂起三分钟，完全不知道在干什么。
🔗 https://x.com/petergyang/status/2053317001976881312

⑥ Nikunj：让模型用「模型时间单位」估工作量
尼昆吉（Nikunj Kothari）分享了一段自定义 system prompt：要求模型估计任务时用「秒/分钟/工具调用次数」报时，而不是「人天」，同时明确区分模型可直接执行的部分和需要人类介入的部分（如 API 注册、部署操作），把后者标注为阻塞步骤。
🔗 https://x.com/nikunj/status/2053159569015328953

📈 商业/观点

⑧ Aaron Levie：专家在 agent 时代反而更值钱
博克斯（Box）CEO 亚伦·莱维（Aaron Levie）写了一篇长论：agent 让进入复杂领域的门槛下降，但有经验的人拥有的判断力和历史直觉，恰恰是在 agent 会犯灾难性错误时识别问题的关键。你会信任一个见过合同执行过程的律师配合 agent，而不是一个从没见过生产系统的纯 prompter。结论：对任何重要领域的专家需求不会下降，而是上升。
🔗 https://x.com/levie/status/2053267097493573921

⑨ Zara Zhang：HTML 是 AI 时代的原生输出格式
扎拉·张（Zara Zhang）援引 Duolingo 创始人的判断：「人不读」。她认为过去的输出格式是为人类操作（编辑 PPT）而设计的，当 AI 接管操作层，输出格式应该转向为人类消费设计——而人类天生是视觉动物，交互式的美丽 artifact 正是 HTML 擅长的。
🔗 https://x.com/zarazhangrui/status/2053291803135410674

🎙 播客

Training Data: ElevenLabs 的 Mati Staniszewski：语音如何成为一切的界面
ElevenLabs 创始人马蒂（Mati Staniszewski）和联创皮特尔（Piotr）是高中同学，一起成长、同班上课、共同创业。他们做语音 AI 的起点是波兰独特的配音文化——所有外语内容只有一个单调声音讲述，这让他们意识到音频领域的巨大空缺。马蒂认为，随着人形机器人普及，语音将成为人与技术的主要界面。他们在 2022 年选择这个方向时，当时业界主流关注的还是加密和元宇宙，音频被视为小众，正是这个时间差给了他们领先窗口。
