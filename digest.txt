🧠 模型

① Grok 4.3 发布：百万上下文窗口 + 电脑操作能力
xAI 发布了 Grok 4.3，拥有 100 万 token 上下文窗口，定价 $1.25/M 输入、$2.50/M 输出，比上一代大幅降价。新版本在 Artificial Analysis 的 Agent 工具调用排行榜和 Vals.AI 企业基准测试（案例法、公司财务）上均排名第一，GDPval-AA ELO 较 Grok 4.20 提升 321 分，是单项基准测试史上最大单次进步。新增"Grok Computer"——可在真实机器上写代码、运行、安装依赖并生成文件的计算机操作 Agent。现已在微软 Azure AI Foundry、Oracle OCI 及 xAI API 上线，所有旧版 Grok 模型已于 5 月 15 日退役并自动迁移至 4.3。
🔗 https://x.com/xai/status/2051703217697010103

② Garry Tan 开源 GBrain：让 Agent 拥有 8 层记忆系统
YC 前 CEO Garry Tan 发布了开源项目 GBrain，MIT 许可证，一条命令即可集成进任意 Agent。他描述这不是"盒装 RAG"，而是一套 8 层协同工作的知识系统，让已经够聪明的 Agent 对用户"如有神助"地了解。目标是让个人 AI 真正成为可能。
🔗 https://x.com/garrytan/status/2055670533451366479

🛠 产品/应用

⑤ Anthropic 为中小企业推出 Claude Cowork：15 个开箱即用 Agent 工作流
Anthropic 发布 Claude Cowork for Small Business，内置 15 个 Agent 工作流，原生对接 QuickBooks、PayPal、HubSpot、Canva、DocuSign、Google Workspace 和 Microsoft 365。典型场景包括月末结账自动化、应收账款催收、合同处理等，所有操作需用户确认后执行。这次发布针对的是一个明显的缺口：中小企业贡献美国 GDP 的 44%，但 AI 深度采用率只有 7%。
🔗 https://www.anthropic.com/news/pwc-expanded-partnership

⑥ PwC 将 Claude 部署至全球数十万专业人员
普华永道宣布全球规模部署 Claude，首批认证了 3 万名美国专业人员。双方成立联合卓越中心，并围绕 Claude 建立了新的"首席财务官办公室"业务线。实测数据：保险核保从 10 周压缩至 10 天，安全任务从数小时缩短至数分钟，交付周期整体缩短最高 70%。这是迄今为止最大规模的专业服务 AI 部署案例。
🔗 https://www.anthropic.com/news/pwc-expanded-partnership
