⑥ "Prompt Injection" 与安全术语命名的重要性
swyx 引用 Simon Willison 的观点，讨论安全术语命名的自明性差异——"prompt injection"因名称直观而广为人知，而"lethal trifecta"等术语则传播效果有限。清晰的命名对安全概念的普及至关重要。
Simon Willison highlights how self-evident naming (like "prompt injection") drives security awareness far better than opaque terms.

🎙 Podcast

Extreme Harness Engineering for Token Billionaires: 1M LOC, 1B toks/day, 0% human code, 0% human review — Ryan Lopopolo, OpenAI Frontier &amp; Symphony

OpenAI Frontier团队工程师Ryan Lopopolo历时五个月，在从未亲自编写一行代码的情况下，借助Codex CLI智能体构建了一个超过百万行代码的内部生产工具。最令人意外的是，项目初期的一个半月效率比手动开发慢了整整10倍，但这一前期投入最终使团队生产力远超任何单个工程师所能达到的水平。本期播客系统介绍了"harness工程"这一新兴学科——即专门为最大化AI智能体效率而设计代码库、构建系统和工作流程的方法论，而非以人类开发者习惯为优先。一个关键技术洞察是：每一代新模型都要求对代码库进行相应适配，例如当GPT-4.3引入后台Shell功能后，模型对阻塞式脚本的耐心下降，团队因此不得不将整个构建系统重构为一分钟内完成。

Ryan Lopopolo, an OpenAI engineer on the Frontier team, built a production-grade internal tool exceeding 1 million lines of code over five months without writing a single line of code himself — relying entirely on Codex CLI agents. Most surprisingly, the first month and a half was actually 10x *slower* than working manually, but the upfront investment in building robust agent tooling ultimately made the team far more productive than any individual engineer could be. The episode introduces "harness engineering" as an emerging discipline — the art of structuring codebases, build systems, and workflows specifically to maximize AI agent productivity rather than human developer preferences. A key technical insight was that each new model generation (GPT-4.1 through later versions) required adapting the codebase to match the model's working style, including overhauling the entire build system to complete in under one minute when GPT-4.3's background shell feature made the model less patient with blocking scripts.
