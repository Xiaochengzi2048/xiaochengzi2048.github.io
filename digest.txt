🤖 Agent / 编程

④ Vercel 开源深度安全扫描 Agent：deepsec
Guillermo Rauch（Vercel CEO）宣布开源 npx deepsec，一个专门做深度代码安全审查的 agent 编排器。他们内部先用，跑了几个主要开源项目后有了信心。配合 Vercel Sandbox 可以跑数千个并行 agent，在几分钟内找到人工团队可能要几个月才能发现的漏洞。
🔗 https://x.com/rauchg/status/2051386798899888539

⑤ Crabbox 0.5.0：支持桌面 VNC 的远程 CI 沙箱
彼得·施泰因贝格尔（OpenClaw 联合创始人）发布 Crabbox 0.5.0：支持桌面/浏览器租用、VNC 和认证 WebVNC、AWS Windows+WSL2、截图+应用启动。同一周他们还实现了用临时 Crabbox + WebVNC 直接在 PR 上录制视频复现和修复 bug，让 QA 流程完全由 agent 完成。
🔗 https://x.com/steipete/status/2051485798613111116

⑥ Anthropic Claude Code Auto Mode：跳过权限但保持安全
Anthropic 工程博客介绍 Claude Code 的新"auto 模式"——用模型分类器代替人工审批，在"手动确认"和"完全跳过"之间走中间路线。分两层防护：输入层扫描提示注入，输出层用 Sonnet 4.6 在执行前判断每个 action 是否危险。内部数据显示用户接受率已达 93%，但仍发生过删远程 git 分支、把 GitHub token 上传到集群等"过度热心"事故。
🔗 https://www.anthropic.com/engineering/claude-code-auto-mode

⑦ 编程前沿的命名之争：vibe coding vs agentic engineering
Simon Willison 本周在博客承认两者正在合流，"比我想要的更近"。同周 Addy Osmani 把可复用的提示组合叫"skill"，Drew Breunig 讨论代码成本趋零后如何重新分配评审/规格/测试的人力，Ibrahim Diallo 则指出 agent 删库责任仍在按回车的人。四位开发者同一周指向同一件事，连名字都还没谈拢。
🔗 https://simonwillison.net/2026/May/6/vibe-coding-and-agentic-engineering/

🔒 安全

🎙 Podcast

Training Data：《Waymo 的 Dmitri Dolgov：2000 万次乘车与全自动驾驶之路》
Waymo 联合 CEO 德米特里·多尔戈夫（Dmitri Dolgov）回顾了从 2005 年 DARPA 挑战到如今每周 400 万英里全自动驾驶的完整历程。核心观点：自动驾驶最难的不是前 90%，而是从 90% 到"超人安全"的最后一截。Waymo 的基础模型是端到端的多模态世界-动作模型，同时驱动驾驶员、模拟器和评审者三个模块。他们已完成 2000 万次全自动乘车，全球 11 座城市运营，今年将进入伦敦和东京。当前每 8 天防止一起严重伤害事故，安全记录是人类驾驶员的 13 倍。
