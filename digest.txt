🧠 模型

① Anthropic 完成 300 亿美元融资，估值超 9000 亿美元首超 OpenAI
本轮由红杉资本、Dragoneer、Altimeter Capital 联合领投，Peter Thiel 的 Founders Fund 和 General Catalyst 跟投。Anthropic 估值约 9000 亿至 1 万亿美元，首次超过 OpenAI（OpenAI 今年 3 月估值为 8520 亿美元）。2026 年 Q2 营收预计达 109 亿美元，同比增长 130%，并有望实现首个季度盈利（5.59 亿美元）。
🔗 https://www.techtimes.com/articles/317066/20260523/anthropic-funding-round-top-30b-900b-valuation-would-surpass-openai-most-valuable-ai-startup.htm

② Google 推出 Gemini 3.5 Flash，成为全球搜索默认模型
Gemini 3.5 Flash 于 5 月 19-20 日 Google I/O 亮相，支持 100 万 token 上下文，API 定价 1.5 美元/百万 token，编程和 Agent 能力超越 Gemini 3.1 Pro 且速度提升 4 倍。Google 称此次为 25 年来最大搜索架构变革——搜索结果页面现在可直接生成自定义图表、交互图形和迷你应用。
🔗 https://blog.google/products-and-platforms/products/search/search-io-2026

③ OpenAI 向 SEC 秘密提交 IPO 招股书 S-1
Goldman Sachs 和 Morgan Stanley 联合承销，JPMorgan 参与，计划 2026 年 9 月上市，目标估值 8520 亿至 1 万亿美元。消息一出，软银股价涨 4.6% 至历史新高。
🔗 https://www.buildfastwithai.com/blogs/ai-news-today-may-24-2026

🤖 Agent/编程

④ Codex 新增「锁屏操控」功能，可在 Mac 熄屏时远程运行
OpenAI 在 5 月 21 日更新中为 Codex 加入"remote locked use"，允许 Agent 在屏幕锁定状态下继续操作 Mac，无需本地活跃会话。同时集成 GPT-Image-1.5 支持图片生成迭代，并开放开源沙箱配置。Codex 的 GitHub 仓库（openai/codex）最新版 rust-v0.132.0-alpha.1 于 5 月 18 日发布。
🔗 https://openai.com/index/introducing-the-codex-app

⑤ Nikunj Kothari：用 Claude Code 逆向工程 API，自动化否则无法操控的网站
Nikunj 分享，通过抓包分析网络请求来逆向工程 API，是配合 Claude Code 自动化任务最有趣的方式之一——许多网站的前端无法「确定性地」通过浏览器自动化，但 API 却可以。
🔗 https://x.com/nikunj/status/2058783316753686558

⑥ Thariq（Bun 作者）：遗留代码库将成为「提炼」新代码的重要来源
Thariq 从 Bun 的重写经历中得出结论：每一款游戏都应该跨平台，所有遗留软件都应该被重写。他认为模型当前还不够完美，但 Bun 的高测试覆盖率使验证变得可行，且模型会越来越强。
🔗 https://x.com/trq212/status/2058576195000660319

⑦ xAI 推出 Grok Build 编程 Agent 和 Grok Voice Think Fast 1.0
xAI 面向 SuperGrok Heavy 订阅用户（300 美元/月）推出 Grok Build beta 版，并同步发布 Grok Voice Think Fast 1.0，定位多步骤工作流的语音 Agent API。
🔗 https://www.pcmag.com/news/elon-musks-xai-launches-grok-build-its-first-ai-coding-agent
