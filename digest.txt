🧠 模型

① Karpathy 加入 Anthropic 预训练团队
前 OpenAI 联创、特斯拉 AI 负责人 Andrej Karpathy 宣布正式加入 Anthropic，加入其预训练团队，负责人是 Nick Joseph。他将组建一支新的内部小组，专注于用 Claude 加速预训练研究。Karpathy 说："我认为未来几年是 LLM 前沿最关键的时期，很难想象还有比这更好的地方了。"此前他经营 AI 教育创业公司 Eureka Labs 约两年，他表示未来还会继续推进教育方向的工作。
🔗 https://x.com/karpathy/status/2056753169888334312

② Gemini 3.5 Flash 发布：专为 Agent 打造的新旗舰模型
Google 在 I/O 大会发布 Gemini 3.5 Flash，明确定位为 Agent 任务和长流程工作，而非聊天。在 MMMU-Pro（多模态）得分 83.6%，Terminal-Bench（代理编程）得分 76.2%，Toolathon（真实任务）得分 56.5%，性能大幅超越 Gemini 3 Flash。Aaron Levie（Box CEO）在内部评测中测得 Gemini 3.5 Flash 在复杂文档任务上提升了 12 个百分点。
🔗 https://x.com/levie/status/2056804573449474527

③ Gemini Omni Flash：Google 第一个"世界模型"
Google 在 I/O 发布 Gemini Omni Flash，号称首个 Omni 多模态模型，支持视频生成、音频、图像与文本的统一处理，具备 Veo 级别的物理理解能力，结合 Gemini 的推理能力，已在 Gemini App 中上线。
🔗 https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/

🤖 Agent/编程

④ Claude Managed Agents 新功能：自托管沙箱 + MCP 隧道
Anthropic 宣布 Claude Managed Agents 两项重要更新：支持在企业自有环境内运行沙箱（self-hosted sandboxes），以及连接私有 MCP 服务器（MCP tunnels）。这意味着代码执行和数据访问都可以留在企业内部安全边界内，解决了此前大企业不敢把代码发出去的顾虑。Claude 官方账号称："沙箱和服务一起运行在你企业已建立的安全边界内。"
🔗 https://x.com/claudeai/status/2056645493493575681

⑤ Vercel Sandbox × Claude Managed Agents 正式集成
Vercel 的沙箱产品已正式 GA，提供给 AI Agent 使用的隔离 Linux 微虚拟机，支持完整文件系统、Shell 和网络访问，专门针对 AI Agent 执行不可信代码的场景。Vercel CEO Guillermo Rauch 宣布与 Claude Managed Agents 深度集成。v0、Blackbox AI、RooCode 等产品都已接入。
🔗 https://x.com/rauchg/status/2056734559048536070

⑥ Google I/O：Project Genie 大幅更新，Street View 打底生成真实世界
Google Labs 发布 Project Genie 重大更新，现在可以用 Google Maps Street View 的实景数据为起点来生成世界模拟，还支持在个人图书馆管理创作内容并对外分享。这是世界模型研究迈向"接地气"现实的重要一步。
🔗 https://x.com/GoogleLabs/status/2056872996988756228

⑦ Cursor / Composer 2.5 成为 AI 编程全流程首选
Cursor 工程师 Ryo Lu 分享工作流：他现在规划、开发、调试全程使用 Composer 2.5，尤其在 UI 工作和 Design Mode 上配合流畅。同日还宣布 Cursor 接入 Jira，可以直接从 Jira 工单出发驱动编程任务。
🔗 https://x.com/ryolu_/status/2056892527626817935

⑧ Swyx 分享四阶段 AI SDLC 框架
Swyx 整理了他认为 AI 开发的四个阶段：维持约 50 个测试 + 写入记忆让 AI 自动做视觉检查；分拆并编辑大型文档结构；以及两个待续阶段。他还注意到"Contextual 被 Windsurf 化了"——指 OpenAI/Google 大手笔买单工具链，独立小厂面临压力。
🔗 https://x.com/swyx/status/2056877529991205072

⑨ Devin 建造者 Scott Wu：用 Claude 让每个工程团队构建软件提速 10 倍
Claude 官方介绍了 Cognition 创始人 Scott Wu 的故事。他的团队正在用 Claude 打造 Devin，目标是让每一个工程团队的软件开发速度提升 10 倍。这是 Anthropic "Problem Solvers" 系列的首期内容。
🔗 https://x.com/claudeai/status/2056805728774402428

📈 商业/观点

⑫ Sam Altman：OpenAI 向每家 YC 批次创业公司投入价值 200 万美元的 Token
Sam Altman 宣布 OpenAI 将向当前 YC 批次（约 169 家公司）的每家初创公司投资价值 200 万美元的 OpenAI Token，换取股权（通过无上限 SAFE）。他称这一策略为"tokenmaxxing"——鼓励创业公司大量使用 AI Token 来构建产品。YC 合伙人称这是"全场最亮的时刻"。
🔗 https://x.com/sama/status/2056933166875857290

⑬ Sam Altman：OpenAI 推出 1-3 年算力预购，帮助企业锁定容量
Sam Altman 表示随着模型越来越强，世界将长期处于算力短缺状态，因此 OpenAI 开始提供 1 至 3 年算力预购折扣，帮助客户锁定容量，同时帮助 OpenAI 自身做更好的规划。他形容这是"双赢"。
🔗 https://x.com/sama/status/2056827105401614656

⑭ Aaron Levie：Token 成本将成为企业 AI 的核心议题
Box CEO Aaron Levie 在与多位世界 500 强 CIO 的晚宴后分享，Token 成本已经是最激烈的讨论话题。各家正在混合使用不同策略但没有人觉得找到了正确答案：有人做成本分摊，有人收紧模型使用权限，有人转向轻量模型。
🔗 https://x.com/levie/status/2056965292753146019

⑮ Nikunj Kothari：AI 正从助手走向同事，再走向自主工作者
Nikunj Kothari 认为，即便是在湾区这种已经深度"AI 化"的圈子里，很少有人真正意识到：AI 已经从助手进化到同事，而自主工作者的阶段近在眼前。虽然"自主性"目前还不够可靠，但框架和模型能力正在把我们推向那个时代。
🔗 https://x.com/nikunj/status/2056865808832397344

⑯ Garry Tan：Tokenmaxxing 确认，GBrain 或是微软当年 WinFS 的现代实现
YC 合伙人 Garry Tan 转发了 Altman 的 tokenmaxxing 内容表示确认，并提了一个历史有趣的类比：他 2003-2005 年在微软时曾参与 WinFS 项目（智能文件系统，最终失败），如今 LLM 可能让这个愿景以 GBrain 的形式重新实现。
🔗 https://x.com/garrytan/status/2056976600294650266

🎙 Podcast

Training Data：《从零重建企业 IT：Serval 创始人 Jake Stauch》
Jake Stauch 是 Serval 的创始人兼 CEO，Serval 被定位为"AI 原生的 ServiceNow"。本期核心观点：自动化的门槛必须低于手动操作，企业才会真正用起来；他们没有 SE 和 SDR 岗位，销售靠 AI 实时回答产品问题；最大挑战不是技术，而是跨大组织的协调和决策效率。最有意思的洞察：企业内个人想要 Agent 自主权，而 IT 部门想要控制权，这一张力正在变成新的"影子 IT"现象。
