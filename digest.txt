① Google Lyria 3 音乐生成 API 全球开放
谷歌在 Gemini API 中开放 Lyria 3 付费预览，支持生成完整歌曲（Pro版～3分钟）和30秒片段（Clip版）。核心创新是自然语言精细控制——用户可指定节奏、歌词、编曲结构，并支持多语言演唱和图像风格推断。格莱美获奖制作人 Yung Spielburg 已用于生产实际短片。版权处理通过 SynthID 水印追踪，训练数据来自 YouTube 授权素材。

📚 论文速报

① Beyond Static Leaderboards: Predictive Validity for Evaluating LLM Agents
研究发现排行榜排名在分布外不稳定——将一个 MCP agent 基准用14种方式重建后，聚合评分排名会无警告翻转。提出"预测有效性"指标衡量样本内排名与样本外排名的相关性。
🔗 https://arxiv.org/abs/2606.19704

② Native Active Perception as Reasoning for Omni-Modal Understanding (OmniAgent)
7B 视频 agent 通过主动感知（POMDP 观察-思考-行动循环）在 LVBench 达到 50.5% 准确率，超越 Qwen2.5-VL-72B 的 47.3%。关键在于将长视频理解重新框架为感知推理问题。
🔗 https://arxiv.org/abs/2606.19341

③ ENPIRE: Agentic Robot Policy Self-Improvement in the Real World
机器人手臂在钉插、拉链、工具使用等任务上自主达到 99% 成功率。系统包含环境（自动复位/评分）、改进（策略精化）、展开（并行评估）、演化（读日志、搜文献、修改训练）四个模块。
🔗 https://arxiv.org/abs/2606.19980
